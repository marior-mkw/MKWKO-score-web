# Créditos

## Fuente
**Racers Delight** por **@ImWhoreHay**.
Fuente proporcionada por el usuario en `Mario Kart World Font.zip`.
El README original indica que busca recrear la fuente de Mario Kart World y
solicita crédito a @ImWhoreHay. Se incluye intacto en `assets/fonts/README.txt`.
El archivo utilizado es `assets/fonts/RacersDelight.otf`.

## Renders de las imágenes de muestra
Mario Render used in showcase images by [@mario64models](https://ko-fi.com/mario64models)
and [@CashBanacho](https://ko-fi.com/CashBanacho).

Este crédito corresponde a los renders de muestra indicados por el usuario.
El frontend utiliza tarjetas y una banda dibujadas con CSS; no incorpora personajes
ni archivos de esos renders. La plantilla PSD no es necesaria para cargar la fuente.
